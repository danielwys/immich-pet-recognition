What happens when you enable it?

The service rechecks the existing review queue and keeps checking new photos. It writes a pet tag in Immich only when all three checks pass. Each pet’s control is saved across restarts.

Made a mistake? Open Tagged, select photos, then choose the correct pet or Remove tags.
